# 트레이딩 제국 — 방치형 (Trading Empire · Idle)

봇을 사서 자동으로 돈을 벌고, 가챠로 뽑고, 꺼놔도 쌓이는 방치형 웹 게임.
순수 클라이언트(HTML/JS 단일 파일) — 서버·백엔드 없음, 진행상황은 브라우저 localStorage에 저장.

## 플레이

- 배포: https://load0117.github.io/trading-empire/
- 로컬: 이 폴더에서 `python3 -m http.server 8000` 후 http://127.0.0.1:8000

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 게임 본체(단일 파일, 자체 완결) |
| `manifest.webmanifest` · `sw.js` | PWA(홈화면 설치·오프라인 캐시) |
| `icon*.png` · `icon.svg` | 아이콘 |
| `gamble.html` | 초기 확률게임 프로토타입(보관용, 랜딩 아님) |

## 특징

- 방치형 루프: 봇(생성기) → 가챠 → 시너지 → 환생/명성(프레스티지) → 엔딩(무한)
- 오프라인 수익 · 일일 출석(연속 보너스) · 업적 · 봇 25대마다 ×2 무한 마일스톤
- 광고 자리 확보됨(`watchAd()`) — 현재는 프로토타입, 배포 시 HTML5 게임 포털 SDK 연결 예정
